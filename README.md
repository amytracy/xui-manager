# XUI Manager

**XUI Manager** — Android-приложение, которое разворачивает [3x-ui](https://github.com/MHSanaei/3x-ui) на вашем VPS и позволяет управлять панелью прямо с телефона.

Это простой аналог AmneziaVPN по идее «свой VPN без ручной настройки»: вы добавляете сервер, приложение само устанавливает и настраивает 3x-ui, создаёт подключение VLESS + Reality и выдаёт готовую ссылку или QR-код для клиента. Руками в консоли ничего делать не нужно.

> XUI Manager — не VPN-клиент. Подключаться можно любым удобным клиентом: Happ, INCY, v2rayNG, Hiddify и другими.

## Возможности

- **Развёртывание в один клик.** Установка 3x-ui на чистый Linux-сервер по SSH, сертификат Let's Encrypt, случайные логин, пароль и порт панели, VLESS + Reality — всё автоматически.
- **Управление клиентами.** Создание, редактирование, включение и отключение, удаление, лимиты и сроки, QR-код и ссылка подписки.
- **Инбаунды.** Список, включение и выключение, удаление, быстрый редактор маскировки Reality и полный редактор, повторяющий форму 3x-ui: популярные протоколы, транспорты, TLS и Reality.
- **Домен и сертификат.** Можно указать домен: приложение проверит DNS и выпустит сертификат Let's Encrypt. Без домена сертификат выпускается на IP.
- **Маскировка (self-steal).** Caddy отдаёт безобидный сайт-заглушку, а Reality при проверке перенаправляет на него трафик. Вместо случайного шаблона можно загрузить свою страницу `index.html` — при установке или позже.
- **Ноды 3x-ui.** Подключение других серверов с 3x-ui, проверка состояния, синхронизация инбаундов.
- **RoscomVPN-маршрутизация.** Готовый профиль для Happ и INCY: российские и белорусские сервисы идут напрямую, остальное — через VPN. По желанию сервер тоже не пропускает трафик в РФ.
- **Обновления.** Приложение само проверяет новые версии себя, 3x-ui и Xray при каждом запуске, а кнопка «Проверить обновления» делает это вручную. 3x-ui и Xray обновляются на сервере и нодах из приложения; для новой версии приложения открывается страница релиза на GitHub, APK скачивается и ставится вручную. Систему сервера тоже можно обновить в одно нажатие.
- **Веб-панель внутри приложения.** Панель 3x-ui открывается во встроенном браузере с автоматическим входом.
- **Русский и английский интерфейс.**

## Чем отличается от AmneziaVPN

AmneziaVPN — это готовый VPN-клиент со своим протоколом и инфраструктурой. XUI Manager решает другую часть задачи: он автоматизирует развёртывание 3x-ui и управление сервером, а для подключения можно использовать привычный клиент. Если нужен «свой VPN на своём сервере за пару минут» — это сюда.

## Установка

1. Скачайте APK на странице [Releases](https://github.com/amytracy/xui-manager/releases/latest).
2. Разрешите установку из этого источника, если Android попросит.
3. Поддерживается Android 8.0 и новее.

## Быстрый старт

1. **Добавьте сервер.** Укажите IP или домен, SSH-порт и доступ: пароль или приватный ключ. Нужен Linux-сервер с systemd и пользователь с sudo (или root).
2. **Нажмите «Развернуть».** Приложение проверит сервер, установит 3x-ui, выпустит сертификат и создаст VLESS + Reality. Прогресс виден в приложении; если соединение оборвётся, развёртывание продолжится на сервере.
3. **Создайте клиента.** Приложение покажет QR-код и ссылку подписки.
4. **Подключитесь.** Отсканируйте QR в Happ, INCY, v2rayNG или другом клиенте.

## Требования к серверу

- Linux с systemd (например, Ubuntu, Debian, AlmaLinux или Rocky).
- Доступ по SSH с sudo или root.
- Открытые порты 22, 80 и 443 (или возможность открыть их в файрволе).
- Для домена — A-запись, указывающая на сервер.

## Безопасность

- SSH-пароли, ключи и токены хранятся в зашифрованном виде в Android Keystore.
- Ключ SSH-сервера запоминается при первом подключении; если он изменится, приложение откажется подключаться.
- Панель и API работают по HTTPS с проверкой сертификата.
- Секреты не попадают в логи развёртывания.

## Для разработчиков

Нужны Android SDK с platform 37 и JDK 17+.

```sh
./gradlew :app:assembleDebug        # debug APK
./gradlew :app:testDebugUnitTest    # тесты на JVM
./gradlew :app:assembleRelease      # release APK с R8
```

Подробности о подписи release-сборки и внутреннем устройстве проекта — в исходниках и комментариях к коду.
